# 🎲 How to Play

Someone always has to read the manual. This is the fix.

How to Play is an AI-powered game companion built for the table — not for 
before the game, when you have time to prep, but during it, when someone's 
confused and everyone just wants to play.

## 🎯 The problem

Every game night has the same tax: someone spends 20 minutes reading rules, 
or you pause mid-game to look up a specific mechanic, or you get to the end 
and realise you've been playing wrong for an hour. Static rulebooks and 
YouTube tutorials don't help when you're mid-round and just need a quick 
answer.

And sometimes, the only real way to learn a game is to play it. How to Play 
makes that possible — so you can start the game and get answers as the 
questions come up, rather than front-loading an hour of prep nobody enjoys.

## ✨ Key features

**💬 Rules Q&A** — ask questions in plain language and get answers in context. 
No page references, no scanning walls of text.

**🚀 First Play Assistant** — guided setup and rule explanations for new games, 
so the first playthrough doesn't take twice as long.

**✅ Setup Checklist** — step-by-step setup instructions to make sure nothing's 
missed before you start.

**📖 Learn Stepper** — structured walkthrough of core mechanics for players 
learning a game from scratch.

**⚡ Quick Rules Sheet** — a condensed reference for players who've played 
before but need a refresher on specifics.

**🎴 Expansion Support** — expansion rules are tracked separately so they don't 
muddy the base game experience.

**📚 Custom Game Library** — add any game, not just the ones pre-loaded. Catan, 
Wingspan, and Ticket to Ride ship by default.

## 🔭 Potential future enhancements

These are ideas on the backlog, not a committed roadmap:

- **👥 Shared table sessions** — one person opens the game, the whole table can 
  ask questions from their own device without everyone crowding one screen
- **🎙️ Voice input** — hands-free rules Q&A for when your hands are full of 
  cards
- **🔢 Player count variants** — rule adjustments and tips that automatically 
  account for how many people are playing
- **🌍 Community library** — crowdsourced game entries and strategy tips, so 
  the library grows beyond what any one person adds
- **🏠 House rules tracker** — save your group's custom rules per game so you 
  don't relitigate them every time
- **📶 Offline mode** — because wifi at a friend's place is never reliable when 
  you need it

## 🛠️ Built with

React, TypeScript, Supabase, Tailwind CSS — prototyped and iterated with 
Lovable.

## 🌱 What I'm learning
